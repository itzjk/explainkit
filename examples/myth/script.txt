# A myth-busting format: state the claim, show the evidence, reveal the fact.
# Myth: "Lightning never strikes the same place twice."

Lightning never strikes the same place twice.
That is what people say. It is wrong.

The Empire State Building is hit about twenty times a year.
The same antenna. The same spot. Over and over.

Why? Lightning follows the shortest path to the ground.
A tall conductor in an open area will win every storm.

A place gets struck again because it is still the best path.
Not once. Not twice. Every time the sky breaks.

Which myth should we bust next? Comment: gravity or magnets.
